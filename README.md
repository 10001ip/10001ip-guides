# 10.0.0.1 Default Credentials Reference

A quick, no-nonsense reference of factory default usernames and passwords for
`10.0.0.1` admin panels — routers and Piso WiFi vendo machines (LPB, AdoPisoft,
PisoFi, JuanFi, TP-Link, and more).

**Live page:** this repo is published with GitHub Pages.

**Full guides:** [10001ip.co](http://10001ip.co/) — the complete 10.0.0.1 and
Piso WiFi reference (portal login, pause time, vouchers, owner business guides).

## Why this exists

`10.0.0.1` is a private gateway address, not a public website. It only loads
while you're connected to the router or vendo that owns it. This reference
saves owners from digging through manuals for the factory login on first setup.

## Security note

Change the factory admin password on first login. The admin password is not the
WiFi password. Never share admin credentials with customers.
